# Python Core Practice

Rebuilding Python fundamentals through tested utility functions.

## Topics

- Functions
- Strings
- Lists
- Dictionaries
- Files
- JSON
- Exceptions
- Logging
- pytest
- Ruff

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
```

## Run tests

```bash
pytest
```

## Lint

```bash
ruff check .
ruff format .
```
